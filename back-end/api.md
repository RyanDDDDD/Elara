1. 注册接口：
路由：/register
方法：POST
需要的前端的参数：
{
    "username": xxx,
    "password": xxx,
    "email": xxx
}
注册成功后，后端返回：{"message": "注册成功"}, 201
注册失败时，后端报错： abort(400, '用户名已存在!')

2. 登录接口：
路由：/login
方法：POST
需要的前端的参数：
{
    "username": xxx,
    "password": xxx,
}
登陆成功后，后端返回：{"message": "登录成功"}, 200
前端传来的参数中有空值，后端报错：abort(400, '用户名和密码都是必填项!')
用户名不存在，登录失败，后端报错：abort(400, '用户名不存在!')
密码错误，登录失败，后端报错：abort(400, '密码错误!')

3. 获取用户信息接口（用于profile）：
路由：/user/<username>     //注意，这里需要前端在用户登录后，自己在缓存存username，用于写请求的url
方法：GET
需要的前端的参数：
无
查询成功，后端返回的值：
{
    "username": xxxxx,
    "password": "********",
    "email": xxxx,
    "user_info": xxxx   //无用字段，暂时忽略
}
查询失败，后端报错：abort(404, '用户名不存在!')   //这个错误不要抛给用户，这是系统内部数据错误。 或者提示系统错误，请联系管理员。用户关掉报错框时直接返回聊天界面


4. 修改用户信息接口（profile界面点save时调用）：
路由：/user/<username>     //注意，这里需要前端在用户登录后，自己在缓存存好用户的username
方法：POST
需要的前端的参数：
{
    "password": "********",
    "email": xxxx,
}
查询成功，后端返回的值：
{
    "username": xxxxx,
    "password": "********",
    "email": xxxx,
    "user_info": xxxx   //无用字段，暂时忽略
}
修改成功后，后端返回：{"message": "用户信息更新成功"}, 200
修改失败时，后端报错：abort(404, '用户名不存在!')   //这个错误不要抛给用户，这是系统内部数据错误。 或者提系统错误，请联系管理员。用户关掉报错框时直接返回聊天界面
