# Elara - Clean Energy Education Platform


## 📋 Overview

Elara is an interactive platform designed to help users understand and explore the field of clean energy. Whether you're a university student, K-12 student, or an experienced professional, Elara provides personalized guidance and information to support your journey in the clean energy sector.

## ✨ Features

- **Interactive Chat Interface**: Ask questions and receive information about clean energy topics
- **Role-Based Experience**: Customize your experience based on your background (university student, K-12 student, or professional)
- **User Authentication**: Secure login and signup functionality
- **Guest Access**: Explore the platform without creating an account
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices

## 🛠️ Technologies

- **Frontend**: React, React Router
- **Styling**: CSS
- **Build Tool**: Vite
- **Deployment**: V0

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or later)
- npm or yarn
